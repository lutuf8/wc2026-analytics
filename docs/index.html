Methodology — Player Performance Index (PPI)
A custom composite that scores every player's individual match performance, using position-specific weights so forwards, midfielders, defenders and goalkeepers are each judged on what matters for their role. Ratings reflect tournament performance to date — they describe what a player has done so far, not a prediction of overall ability. Early in the competition samples are small, so values carry inherent uncertainty.
Forwards
0.30(goals) + 0.25(rating) + 0.15(assists) + 0.10(shots_on_target) + 0.10(dribbles) + 0.10(key_passes)
Midfielders
0.25(rating) + 0.25(key_passes) + 0.20(pass_accuracy) + 0.15(assists) + 0.10(duels_won) + 0.05(goals)
Defenders
0.30(rating) + 0.25(duels_won) + 0.20(interceptions) + 0.15(tackles) + 0.10(fouls_drawn)
Goalkeepers
0.40(rating) + 0.25(saves) + 0.20(save_ratio) + 0.15(clean_sheet_bonus)
Component scaling
Each raw stat is scaled to a 0–10 range against a realistic single-match ceiling for that stat (e.g. a hat-trick anchors the goals scale), then combined using the position weights above.
Baseline anchoring
final = 6.0 + (raw_ppi − 5.0) × 0.7
Scores are anchored to a 6.0 baseline representing an average professional performance, with contributions moving a player up or down from there. This mirrors how established football rating systems are built and keeps small early-tournament samples from producing extreme outliers (a form of regression toward the mean).
Cross-position comparison
To rank players from different positions on one board, each score is compared against its position's tournament average once enough matches exist. Until a position has a stable sample, the raw position score is used directly to avoid distortion from a tiny early dataset.
