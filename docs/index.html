Methodology — Player Performance Index
A custom composite scoring each player 0–10 per match with position-specific weights, normalised across positions for fair cross-comparison.
PPI_forward = 0.30(goals) + 0.25(rating) + 0.15(assists) + 0.10(shots_OT) + 0.10(dribbles) + 0.10(key_passes)
PPI_overall = (PPI_position / position_average) x 10
Each raw stat normalised to 0–10 before weighting. Position auto-detected from lineups. Weights calibrated on live tournament data.
